# Wondaro

Your next adventure starts with a spin.

This repository is the Wondaro brand and interface layer: design tokens, provisional logo files, and the screens for discovery. The wheel chooses with a uniform, independent index. Partnerships do not influence that choice.

```bash
npm install
npm run dev
```

Dutch and English live under `/nl` and `/en`. The logo files in `public/brand` are provisional and can be replaced without changing the screens.
