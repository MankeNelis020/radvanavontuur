# Provisional Wondaro marks

These SVG files are a provisional interpretation of the Wondaro direction: a circular discovery mark, a landscape, a winding path, a hint of north, warm sunlight, and a forest-green ground.

They are not the approved final vector logo.

Replace these files to update the interface:

- `logo-horizontal.svg` — primary horizontal logo
- `logo-compact.svg` — compact logo for the navigation bar
- `icon.svg` — app icon
- `logo-mono.svg` — single-ink mark for light backgrounds

`app/icon.svg` is the favicon copy of `icon.svg`. Update both together.
